# Assista-gratis - Player estilo Kwai

App que roda vídeos da memória automaticamente igual Kwai / TikTok.

## Como usar
1. Acesse: /kwai.html
2. Clique em ESCOLHER SEUS VIDEOS DA MEMORIA
3. Selecione os .mp4
4. Arraste pra cima - toca automático

## Arquivos
- `index.html` - Escala 5x1
- `kwai.html` - Player automático de vídeos
- `manifest.json` - Pra instalar como app
